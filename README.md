## 便宜的代价：带宽、线路、退款条款

**带宽是最大的隐性成本。** 阿里云美国节点带宽单独计价，30 元/M/月，包年包月 5Mbps 就是 150 元/月。一台 2核4G 的突发性能型实例月价 159 元，带宽几乎和机器一个价。第三方报价页上那些“2核4G 三百多”的数字，通常只是实例费，加上 5M 带宽和 40G 高效云盘，账单很容易翻倍。买之前一定要问清楚：报价含不含带宽，含多少 M。

**“不限流量”和“不限速”是两回事。** 华纳云全系 5M 带宽、不限流量，意思是速度封顶 5M，随便跑多少。天下数据原生 IP 是 20M 或 30M 不限流量，同理。666clouds 反着来：带宽给到 200Mbps 甚至 1Gbps，但月流量有上限，800GB 到 4TB 不等，超了要么买流量包要么限速。前者适合稳定持续的小流量站点，后者适合突发大带宽、平时跑不满的场景。哪种划算，看你一个月的实际出流量。

**线路名字要能对上自己的用户。** CN2 GIA 是电信的高质量回程，国内访问延迟低、晚高峰稳，价格也高；9929 是联通的优质线路，三网回程比较均衡；4837 是联通国际线路，带宽大、单价低，国内访问不如前两条；NTT、GTT 和国际带宽这类，主打的是欧美本地和全球互联，国内访问就是普通水平。

这里有一句官方自己说的话值得抄下来。华纳云产品页的常见问题里写着：“美国云服务器主要覆盖欧美地区……电信、移动、联通访问美国云服务器速度一般。如果您的访客群主要在大陆、香港及亚太区，建议选用三线极速直连的香港云服务器。”卖美国节点的商家自己承认国内访问一般，这句话比任何测评都实在。访客主要在中国大陆、香港和亚太的，美国节点不该是你的第一选择。

**退款和变更条款，买之前看清楚。** 天下数据的产品页明确写了不支持降级配置、不支持销毁退款、不支持按小时付费、更换主 IP 不支持、禁用 25 端口。华纳云的活动页写的是续费同价，但这类承诺最好在结账页再确认一遍。666clouds 的套餐页上我没看到退款条款，这一点下单前建议先问清楚再付。

## 常见问题

### 美国云服务器需要备案吗？

不需要。美国节点免备案，付款后即可开通使用，这是它相对国内节点最直接的便利。华纳云和天下数据的产品页都写明了这一点。

### 1核1G 到底够不够用？

个人博客、静态展示页、单账号运营、API 中转够用。日访问量上到几千，或者要在一台机器上同时跑数据库和应用，1核1G 会明显吃紧，直接上 2核4G。

### 为什么同样是 2核4G，价格能差一倍？

差在带宽和线路。天下数据原生 IP 135 元/月给的是 30M 不限流量，洛杉矶云 280 元/月给的是 100M 带宽加 3T 流量，华纳云 133.7 元/月给的是 5M CN2 加不限流量。三者的带宽成本和回程成本完全不同，CPU 和内存反而是最不值钱的部分。

### 美国节点国内访问快吗？

看线路。CN2 GIA 和 9929 这类优化回程，国内访问延迟和晚高峰表现明显好于普通国际线路。但华纳云自己在产品页写明，三网访问美国节点“速度一般”，访客主要在大陆和亚太的建议选香港节点。做国内生意的话，美国节点通常不是最优解。

### 年付一定比月付划算吗？

不一定。华纳云、阿里云这类年付有实打实的折扣，华纳云 2核4G 年付省 458 元。666clouds 大部分套餐年付就是月付乘 12，只有那个 299 元的特价套餐值得抢。

要下单的话，先想清楚两件事：你的站一天来多少人，访客主要在哪。人在欧美的，1核1G 配 CN2 GIA 或 9929 起步就够；人在国内的，美国节点本身就不是最优解，先去看香港节点；预算能压到 299 元一年的，先确认那批特价还有没有货，再看常规套餐。
